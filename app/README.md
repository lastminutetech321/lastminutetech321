# Application Layer 

This directory contains the application-facing components of Nautical Compass.

At present, no executable business logic is active.

## Purpose

The application layer exists to:
- Collect user-provided inputs
- Structure information for analysis
- Display outputs governed by approved frameworks
- Interface with users in public and private contexts

The application does not provide professional services.

## Current State

Status:
- Structure only
- No active processing logic
- No automated decision-making
- No external integrations enabled

All behavior is constrained by governance.

## What May Live Here (Future)

Potential components include:
- Intake interfaces
- Analysis pipelines
- User dashboards
- Reporting views
- Communication adapters

All components must:
- Respect governance constraints
- Avoid implied guarantees
- Avoid advisory representations
- Remain configurable and revocable

## Explicit Limitations

The application:
- Does not provide legal advice
- Does not provide financial advice
- Does not replace licensed professionals
- Does not act on behalf of users
- Does not initiate enforcement actions

Outputs are informational and analytical only.

## Dependency Rule

No application feature may:
- Expand user authority
- Circumvent governance
- Persist data beyond approved retention rules
- Represent itself as institutional approval

Governance defines the ceiling.
The application operates beneath it.
